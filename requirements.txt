# What you get with just this file: the full news dashboard, AI tools,

#   - bcrypt            -> the optional login gate (NEWSPULSE_AUTH_ENABLED,
#                          off by default anyway)
#
# All of the above are handled by graceful degradation already built into
# the code (see PROJECT_REPORT.md) — the app does NOT crash without them,
# it just quietly runs without those specific features. If you later want
# them, use the full requirements.txt (includes this list plus those five
# packages) with a self-hosted Docker deployment instead.
